# Platform 8 9/4 v0.20.4

This release makes the unified Favourites list compact.

## Changed

- Every favourite is collapsed to a single row by default.
- The route heading and Open, Run/Pause/Resume, Remove and expand controls share that row.
- Expanding an individual favourite reveals its run state, freshness and next three train summaries.
- Other favourites remain collapsed, keeping the route-search screen compact.

All live polling, background runs, widgets, reason-code descriptions and saved-route migration remain unchanged.
