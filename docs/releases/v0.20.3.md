# Platform 8 9/4 v0.20.3

This release removes the duplicate Favourites and Watching lists.

## Changed

- Favourites are now the single saved-route list.
- Each favourite can be opened, run, paused, resumed or removed in place.
- Running favourites retain live summaries and the 30-minute background monitoring lease.
- Existing routes from the former Watching list migrate into Favourites automatically.
- Removing a favourite also stops and removes its retained background run state.
- The route screen only offers continued running after the route has been saved as a favourite.

Foreground route polling remains automatic whenever a route is open. Home-screen widget live updates continue to use the same monitoring service and observation store.
