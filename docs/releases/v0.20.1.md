# Platform 8 9/4 v0.20.1

This release consolidates the complete Android project and the newer live-route implementation into one canonical repository.

## Included

- Automatic route polling with configurable 15, 30 or 60 second cadence.
- TOTP-style freshness indicator and independent railway-data age.
- Stable RID-based service rows and durable observation history.
- Hidden and suppressed Staff platform visibility with Public-feed comparison.
- Passenger-only calling-point lists and route-centric arrival times.
- Darwin delay, cancellation and diversion codes with reference descriptions and TIPLOC context.
- Formation and coach-loading data where supplied.
- London King's Cross/St Pancras aggregation through `London (Any)`.
- Background route watching and disruption notifications.
- Configurable live departure-board home-screen widget.
- Full station directory asset and updated Platform 8 9/4 launcher artwork.

## Validation

- 14 JVM regression tests pass.
- Android lint passes.
- Debug APK assembly succeeds with Android Gradle Plugin 9.3.0, Gradle 9.5.0 and JDK 17.

## Installation

Download `Platform-8-9-4-v0.20.1-debug.apk` from the GitHub release assets. Android may require permission to install applications from the browser or file manager used to open the APK.

Existing installations using application ID `uk.ac.rawrail` can be upgraded in place when signed with the same debug key. API credentials are never included in the APK or repository.
