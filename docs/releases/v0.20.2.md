# Platform 8 9/4 v0.20.2

This release fixes Darwin delay and cancellation descriptions.

## Corrected

- Uses the separate Rail Data Marketplace Reference Data consumer key rather than the Staff or Public key.
- Calls the correct `/LDBSVWS/api/ref/20211101/GetReasonCodeList` operation.
- Parses direct arrays and wrapped or case-varied Reference Data JSON responses.
- Refreshes immediately after Reference Data settings change instead of retaining a failed lookup cooldown.
- Shows a useful configuration message when a numeric code cannot yet be resolved.
- Uses resolved reason text in watch summaries when it is available.

Code `812`, for example, resolves to “This train has been delayed by engineering works not being finished on time” using Darwin's current reference catalogue.

## Setup

Subscribe to the RDM product named **Reference Data**. In app settings, paste that product's consumer key and the `GetReasonCodeList` endpoint shown on its Specification tab. The consumer secret is not used by this REST operation.
